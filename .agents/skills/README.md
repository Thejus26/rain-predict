# Skills

Custom skills and slash commands for the **Tea Plantation Rain Prediction System** firmware and embedded engineering workspace. Each skill resides in its own subfolder with a `SKILL.md` instruction file.

- `feature/` - Full lifecycle workflow command for loading specs, starting branches, implementing firmware modules/drivers, testing, reviewing, and completing features.
- `research/` - Researches hardware components, sensor datasheets, communication protocols, and meteorological prediction algorithms, generating documentation into `docs/` or `context/`.
- `cleanup/` - Performs firmware housekeeping tasks (stale TODOs, orphaned source/header files, bare integer types, magic numbers, header guards, debug prints).
- `list-components/` - Lists and categorizes firmware modules, drivers, middleware, and application components across the project layers.
